# CORVON RTK Dual Antenna Configurator

A React + TypeScript configurator for dual-antenna RTK setups.

This tool helps you:
- set Master/Slave antenna offsets in 3D (NED convention)
- preview antenna placement visually
- generate ready-to-use parameters for ArduPilot and PX4
- copy individual parameters or all parameters at once

Online demo: https://holydust.github.io/rtk-dual-antenna-config/
